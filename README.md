## Latar belakang dan tujuan
* Website Just-Tip hadir sebagai platform layanan proxy purchasing (jasa titip) yang praktis dan transparan bagi calon pelanggan. Banyaknya pembeli yang kesulitan mendapatkan barang dari lokasi atau acara tertentu mendorong dibuatnya landing page ini. Website ini bertujuan untuk memberikan informasi yang jelas mengenai katalog layanan, keunggulan jastip, alur pemesanan, serta kontak resmi Just-Tip, sehingga memudahkan pengguna dalam memesan barang impian mereka secara cepat, mudah, dan terpercaya.
